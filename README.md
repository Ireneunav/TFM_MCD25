# TFM_MCD25
En este repositorio se encuentran los archivos y los códigos que se usaron en el TFM "Desarrollo de un pipeline para la extracción de datos y el entrenamiento de modelos de predicción de contaminantes ambientales", por Irene Iribarren.

A pesar de que los datos utilizados en el trabajo provienen de fuentes públicas, se ha llevado a cabo un trabajo sobre ellos tanto por parte de la autora como de colaboradores del proyecto que hacen que no se publiquen en este repositorio.
